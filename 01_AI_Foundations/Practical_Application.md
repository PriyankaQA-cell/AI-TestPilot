# Practical Application

## How I Can Use AI in Manual Testing

After completing this module, I identified several practical ways to use AI in my daily QA activities.

### Requirement Analysis

AI can summarize lengthy Business Requirement Documents and identify ambiguities, missing requirements, and potential risks.

---

### Test Scenario Generation

AI can generate functional, negative, boundary, usability, and accessibility test scenarios from requirements.

---

### Test Case Design

AI can assist in creating detailed test cases with steps, expected results, preconditions, and priorities.

---

### Bug Reporting

AI can improve bug report quality by generating clear titles, reproduction steps, expected results, actual results, and impact descriptions.

---

### Documentation

AI can help create:

- Test Plans
- Requirement Traceability Matrix (RTM)
- Release Notes
- Meeting Minutes
- Status Reports

---

## Conclusion

This course provided the foundation required to begin integrating AI into Software Testing and Project Management workflows while ensuring that all AI-generated outputs are reviewed using professional judgment.
