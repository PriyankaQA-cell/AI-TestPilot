# Learning Reflection

## Why I Learned Git & GitHub

As I transition into becoming an AI-enabled QA professional, I realized that Git and GitHub are essential skills used across software development teams.

Beyond version control, GitHub also serves as a platform to showcase projects, certifications, technical documentation, and continuous learning.

---

## What I Learned

Through this course, I gained a clear understanding of how Git tracks changes and how GitHub hosts repositories for collaboration.

I also learned the importance of repositories, commits, branches, and Markdown documentation.

---

## Challenges

Initially, understanding the concepts of repositories and branches was slightly confusing because I had limited exposure to version control systems.

After creating repositories and completing hands-on exercises, these concepts became much clearer.

---

## My Biggest Learning

One of my biggest realizations was that GitHub is not only for software developers.

QA Engineers, Project Managers, Business Analysts, and Project Coordinators can also use GitHub to manage documentation, collaborate with teams, and build a strong professional portfolio.
