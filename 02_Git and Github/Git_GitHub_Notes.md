# Git & GitHub Notes

## What is Git?

Git is a distributed version control system that helps track changes made to files over time.

Instead of saving multiple copies of the same document, Git maintains a complete history of changes, allowing users to review, restore, or compare previous versions whenever required.

---

## Why Version Control?

Version control helps teams collaborate efficiently by:

- Tracking every change made to a project(who,when,what)
- Preventing accidental loss of work
- Restoring previous versions if required
- Supporting multiple contributors simultaneously

---

## What is GitHub?

GitHub is a cloud-based platform that hosts Git repositories.

It enables developers, testers, project managers, and technical teams to collaborate, manage projects, review changes, and maintain documentation in a centralized location.

---

## Repository

A repository (repo) is a storage location that contains project files, documentation, and version history.

Each repository can have multiple branches and contributors.

---

## Commit

A commit is a snapshot of changes made to a repository.

Each commit includes a meaningful message describing what was changed.

Example:

```
Added AI Foundations module
```

---

## Clone

Cloning creates a local copy of an existing GitHub repository on a computer.

This allows work to continue locally before pushing updates back to GitHub.

---

## Push

Push uploads local commits to the remote GitHub repository.

---

## Pull

Pull downloads the latest changes from GitHub to the local repository.

---

## Branch

A branch is an independent line of development.

Branches allow new features or changes to be developed without affecting the main project until they are reviewed and merged.

---

## Merge

Merging combines changes from one branch into another.

---

## Markdown

Markdown is a lightweight formatting language used for creating documentation on GitHub.

It supports:

- Headings
- Lists
- Tables
- Images
- Links
- Code blocks

---

## Key Learnings

- Git tracks changes efficiently.
- GitHub enables collaboration.
- Meaningful commit messages improve project history.
- Version control is valuable for both code and documentation.
- GitHub is an excellent platform for building a professional portfolio.
