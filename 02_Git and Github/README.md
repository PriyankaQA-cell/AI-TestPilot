# Git & GitHub Fundamentals

## Overview

This module documents my learning journey through the GitHub Skills – Introduction to Git course.

The primary objective of this module was to understand the fundamentals of Git and GitHub, learn how version control works, and use GitHub to maintain a structured portfolio of my AI learning journey.

As a Manual QA Engineer and Project Coordinator, learning Git and GitHub enables me to collaborate effectively with development teams, maintain version-controlled documentation, and showcase my work professionally.

---

## Learning Objectives

After completing this module, I can:

- Explain the purpose of Git and Version Control.
- Understand the relationship between Git and GitHub.
- Create and manage repositories.
- Clone repositories locally.
- Track changes using commits.
- Push local changes to GitHub.
- Pull updates from remote repositories.
- Understand the purpose of branches.
- Create professional repositories using Markdown.
